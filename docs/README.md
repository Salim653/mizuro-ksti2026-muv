# Dokumentasi

Indeks dokumen proyek. Seluruh dokumen untuk pembaca repositori ditulis dalam Bahasa Indonesia.

| File | Isi |
|---|---|
| `KSTI-2026-MAV-GUIDEBOOK-RECAP.md` | Ringkasan guidebook KSTI 2026: aturan robot, lintasan, alur run, penilaian, daftar inkonsistensi, dan implikasi persepsi. |
| `project-notes/project-ksti-2026-mav.md` | Catatan keputusan proyek: hardware yang dimiliki, pembalikan budget frame, keputusan sasis FRP side-plate, pilihan MCU bodi, dan pertanyaan terbuka. |
| `project-notes/reference-ksti-arena3d-dataset.md` | Catatan dataset arena-3d sintetis beserta ground truth yang sudah menyertainya. |
| `project-notes/reference-ksti-model-sim.md` | Catatan testbed simulasi model lajur, aturan timing simulasi, dan hasil pengukuran GPU laptop. |
| `PANDUAN-LANJUTAN-TIM.md` | Panduan serah-terima: arsitektur kode, status lokal Jetson, cara menjalankan dan memeriksa sistem, kesenjangan implementasi, serta urutan aman untuk melanjutkan pekerjaan. |

⚠️ Ketiga file di `project-notes/` adalah catatan kerja internal yang diimpor apa adanya dan masih berbahasa Inggris. Isinya keputusan teknis, bukan dokumentasi untuk pembaca umum. Jangan menganggapnya sebagai spesifikasi final: beberapa butir masih berupa pertanyaan terbuka yang menunggu konfirmasi di Technical Meeting.

Dokumen sumber asli (`GUIDEBOOK PESERTA MINI AUTONOMOUS VEHICLE KSTI 2026.pdf`) dan aset peta lintasan tetap berada di workspace proyek, tidak disalin ke repositori ini.
